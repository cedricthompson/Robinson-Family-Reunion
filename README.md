# Robinson Family Reunion

The website for the Robinson Family Reunion: a photo slideshow, reunion highlights and a gallery.

## Adding photos

1. Upload the new `.jpg` into the `images/` folder.
2. Open `script.js` and add a line to the `PHOTOS` list, for example:
   `{ file: "photo-19.jpg", caption: "Cousins at the cookout" },`
3. Commit. The site updates in about a minute.

## Hosting

The site is served by GitHub Pages from the `main` branch (Settings → Pages).
